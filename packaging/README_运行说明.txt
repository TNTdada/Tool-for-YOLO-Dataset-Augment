YOLO Dataset Augmenter 运行说明
================================

请双击本文件同目录下的 YOLODatasetAugmenter.exe 启动程序。

注意：
1. 必须保留整个 YOLODatasetAugmenter 文件夹。
2. 不要单独复制 EXE；程序需要同目录下的 _internal 文件夹。
3. build 或 .pyinstaller-build 中的 EXE 是 PyInstaller 中间文件，不能作为发布程序运行。
4. 正确的发布程序路径是 dist\YOLODatasetAugmenter\YOLODatasetAugmenter.exe。
